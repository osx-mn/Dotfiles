# Dotfiles

Archivos de configuración personal para herramientas multiplataforma. El objetivo es mantener las mismas configuraciones (terminal, shell, editor, etc.) sincronizadas entre distintas máquinas.

## Contenido

- `starship/` — configuración del prompt (Starship)
- `wezterm/` — configuración de la terminal (WezTerm)

## Uso

Cada carpeta corresponde a una herramienta. Symlinkear o copiar el archivo correspondiente a su ubicación esperada por cada programa.
